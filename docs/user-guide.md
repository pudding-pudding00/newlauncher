# User guide

## Files on SD and library device

`<lib>` is `usb` or `sd` (setting `library` in `config.ini`).

```
sd:/apps/newlauncher/        boot.dol, meta.xml
sd:/newlauncher/config.ini   settings (created with defaults on first start)
sd:/newlauncher/emulators.ini   emulator paths and arguments (created on first start)
sd:/newlauncher/n64_vc.ini   N64: game → VC inject channel (created on first save)
sd:/newlauncher/games.ini    N64: start method per game (created on first save)
sd:/newlauncher/favorites.ini, history.ini, log.txt
sd:/newlauncher/music/*.ogg   background music (Ogg Vorbis)
<lib>:/newlauncher/cache/index.bin   game index (written by the launcher)
<lib>:/newlauncher/cache/meta.bin    metadata (prepare_meta.py)
<lib>:/newlauncher/covers_src/<stem>.png   cover sources (prepare_covers.py or "Download missing covers")
<lib>:/newlauncher/cache/covers/<stem>.tex covers as CMPR textures (generated by the launcher)
<lib>:/wbfs/Title [ID6]/ID6.wbfs|.iso    Wii
<lib>:/games/Title [ID6]/game.iso        GameCube
<lib>:/roms/nes|snes|gb|gbc|gba|n64/     ROMs
```

## Covers and metadata

A PC script generates metadata (title, year, publisher, genre) as `<lib>/newlauncher/cache/meta.bin`.
Wii and GameCube titles come from `wiitdb.xml` by [GameTDB](https://www.gametdb.com/) (download "wiitdb.zip"
and unpack it). Retro titles come from the libretro No-Intro DATs, which the script downloads itself
(`--offline` skips them, `--dat-dir` uses your own DATs):

```bash
python tools/prepare_meta.py --wiitdb wiitdb.xml --lang EN E:/
```

`--lang` selects the language of Wii/GameCube titles (`EN`, `DE`, `FR`, `JA`, …); English is the fallback.

A second script downloads retro box art from libretro-thumbnails into `<lib>/newlauncher/covers_src/`
(existing PNGs are kept, `--force` downloads them again):

```bash
python tools/prepare_covers.py E:/
```

The launcher can download covers itself: HOME menu → Settings → "Download missing covers". The region comes
from the setting "Cover region" (`[covers] region` in `config.ini`: `auto` = system language, otherwise `EN`,
`DE`, `FR`, `US`, `JA`), falling back to `EN`, `US` and `JA`. Progress is shown at the bottom and a dialog
sums up at the end.

Each PNG is converted into a CMPR texture under `<lib>/newlauncher/cache/covers/` the first time it is shown.
After replacing a cover in `covers_src`, use "Clear cover cache" (or delete the matching `.tex`), otherwise
the old texture stays.

## Emulators

NES, SNES, GB, GBC and GBA start through emulator DOLs on the SD card. The launcher loads the DOL, passes the
ROM as `argv` and chainloads into it. `sd:/newlauncher/emulators.ini` sets the DOL and argument scheme per
console. If the file is missing it is created with these defaults:

| Console | DOL | `args` |
|---|---|---|
| `nes` | `sd:/apps/fceugx/boot.dol` | `{dir}\|{file}` |
| `snes` | `sd:/apps/snes9xgx/boot.dol` | `{dir}\|{file}` |
| `gb`, `gbc`, `gba` | `sd:/apps/vbagx/boot.dol` | `{dir}\|{file}` |
| `n64_not64` | `sd:/apps/not64/boot.dol` | `{path}` |
| `n64_wii64` | `sd:/apps/wii64/boot.dol` | `{path}` |

`args` is a `|`-separated list; each entry becomes one `argv` element after `argv[0]` (always the DOL path).
Placeholders:

- `{dir}`: folder of the ROM, with a trailing `/`
- `{file}`: file name
- `{path}`: full path

Missing entries fall back to the defaults. Before starting, the launcher checks that the DOL exists and is
valid and that the ROM is present; otherwise it shows a dialog and keeps running.

### Installing and updating

HOME menu → Settings → "Emulators" shows the state of each emulator (FCE Ultra GX, Snes9x GX, Visual Boy
Advance GX, Not64, Wii64, Nintendont): not installed, up to date, update available or unknown version. Opening
the page does not use the network; "Check for updates" loads the Open Shop Channel list. A on an emulator
installs or updates it, "Update all" takes every one with an update or an unknown version. B cancels a running
download.

The source is set in `config.ini`:

```ini
[emulators]
repo = https://hbb1.oscwii.org/hbb
```

The launcher downloads the ZIP to `sd:/newlauncher/tmp/`, checks size and CRC, unpacks it there and only then
moves the files: files under `apps/` are replaced, all others (for example emulator settings) are only created
if missing, and `boot.dol` comes last. State and version are remembered in
`sd:/newlauncher/emulators_installed.ini`. If the card lacks space for the ZIP plus its content, the download
does not start.

The same works on a PC directly onto the card, with the same rules and the same `emulators_installed.ini`:

```bash
python tools/wii_deploy.py E: --emulators                 # everything in the catalog, asks first
python tools/wii_deploy.py E: --emulators fceugx not64 --yes
```

Without names the tool takes all six emulators and skips those that are up to date. Without `--yes` it first
lists the packages with version and size and downloads only after you type `j` (yes). `--repo URL` sets another
source. Exit code 0 = done, 1 = declined, 2 = error (unknown name, network, broken package; the card then stays
unchanged).

## N64

An N64 game starts in one of three ways. Without your own choice the launcher takes the first available one:

1. **VC inject:** the game is mapped to a channel in `n64_vc.ini` and the channel is installed.
2. **Not64:** the DOL from `[n64_not64]` exists.
3. **Wii64:** the DOL from `[n64_wii64]` exists.

If none is available, a message appears at start.

In the details of an N64 game, press Up to reach the "Start method" row; Left and Right switch between
"Automatic" and the available methods. The choice is saved to `games.ini` immediately. If a chosen method is
later unavailable, the automatic choice applies again and the details say why.

```ini
; sd:/newlauncher/games.ini
; values: vc | not64 | wii64 (comments only on their own line)
[n64_method]
n64/Super Mario 64 (Europe).z64 = not64

; sd:/newlauncher/n64_vc.ini (title ID as 16 hex digits)
[map]
n64/Mario Kart 64 (Europe).z64 = 000100014E4B5450
```

You can also map channels in the launcher: HOME → Settings → "Map VC injects". It lists all N64 games; Left and
Right pick an installed channel or none, A accepts the name suggestion, B saves and closes. Channels are shown
with their banner name, or the title ID if the name cannot be read.

## GameCube

GameCube games start through **Nintendont** (version 6.493 or newer).

- Nintendont lives at `sd:/apps/nintendont/boot.dol`; set another location in `emulators.ini` under
  `[nintendont] dol = …`.
- Games are on SD or USB as `games/<Title> [ID6]/game.iso`, the second disc as `disc2.iso` in the same folder.
- Before starting, the launcher checks that the DOL is readable and its version string (`$$Version:x.y`) is at
  least 6.493.
- It passes the game path to Nintendont as `NIN_CFG` (version 10) in `argv[1]`: memory card emulation on
  (251 blocks), up to four controllers, automatic video mode and language, Nintendont defaults for the rest.
- Paths below the library device may be at most 254 characters long.

**Start the launcher from its Homebrew Channel entry, not via wiiload.** Nintendont needs direct hardware
access (AHBPROT disabled). The Homebrew Channel grants it only to apps with `<ahb_access/>` in `meta.xml` that
it starts itself; otherwise the launcher reports that hardware access is missing. Dolphin needs nothing here.

For diagnosis on real hardware only: `[debug] ignore_ahbprot = 1` skips the check. Nintendont still will not
start.

## Controls

| Action | Wii Remote | Nunchuk | GameCube controller |
|---|---|---|---|
| Navigate | D-pad | Stick | Stick, D-pad |
| Point | IR pointer | – | – |
| Confirm | A | – | A |
| Back | B | – | B |
| Switch console | − / + | – | L / R |
| Toggle favorite | 1 | – | Y |
| Search / A–Z | 2 | – | X |
| HOME menu | HOME | – | Start |
| Debug overlay | 1 + 2 | – | Z + Start |

- **A–Z:** opens the jump bar; a letter jumps to the first title (or the next letter if there is none). Press
  "Search" there for the on-screen keyboard.
- **Search:** filters live across all consoles, ignoring case, accents and No-Intro tags; B leaves search mode.
- **Details:** A on a game; "Start" launches it.

The gear at the bottom right switches the appearance for the running session (light → dark → automatic); the
"Appearance" setting makes it permanent.

## Settings

HOME → Settings opens the list. Up and Down select a row, Left and Right change the value, A runs an action,
B closes and saves to `sd:/newlauncher/config.ini`. Language, appearance, sounds and music apply immediately;
the library device after a restart.

| Setting | Values | Default | `config.ini` |
|---|---|---|---|
| Language | Automatic (system language), German, English | Automatic | `[general] language = auto\|de\|en` |
| Appearance | Light, Dark, Automatic by time | Light | `[theme] mode = light\|dark\|auto` |
| Dark from / until | Time | 19:00 / 07:00 | `[theme] dark_from`, `dark_to` (`HH:MM`) |
| Music | on/off, volume 0–100 | on, 60 | `[audio] music = 0\|1`, `music_volume` |
| UI sounds | on/off | on | `[audio] sounds = 0\|1` |
| Library device | USB, SD | USB | `[general] library = usb\|sd` |
| Cover region | Automatic, EN, DE, FR, US, JA | Automatic | `[covers] region` |

The list also offers actions such as "Rescan library", "Download missing covers", "Map VC injects" and the
cloud save menu.

### Music

The launcher plays all `.ogg` files (Ogg Vorbis, mono or stereo) from `sd:/newlauncher/music/` in random order
and reshuffles after each round without playing a track twice in a row. Without files it stays silent.
Unreadable files are skipped; if every track of a round fails, music turns off for the session. Sound stops
before a game or channel starts and when leaving.
